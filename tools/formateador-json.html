Formateador y validador JSON

Pega tu JSON para darle formato legible, minificarlo o comprobar que es válido. Si hay un error, te mostramos la línea y la columna exactas con una explicación clara. Incluye vista de árbol para explorar la estructura.

Cómo usar el formateador JSON

  1. Pega tu JSON en el cuadro de texto.
  2. Pulsa «Formatear» para verlo con sangría legible, o «Minificar» para compactarlo.
  3. Pulsa «Validar» para comprobar si es correcto: si hay un error, verás la línea, la columna y una explicación.
  4. Usa la «Vista de árbol» para explorar documentos grandes expandiendo y contrayendo secciones.
